Sobre o app

O CityLab Security é um sistema de apoio para monitoramento em tempo real. Ele usa a camera para reconhecer rostos cadastrados, identificar pessoas e destacar alertas visuais durante a transmissao.

Quem cuida

O projeto e mantido por Diogo de Lorenzi Pinheiro, Mariana Lebrão Murauskas e Prof. Mario Pardo, com foco em criar uma ferramenta simples de testar, evoluir e demonstrar em ambiente academico.

Tecnologias

A aplicacao usa FastAPI no servidor, MongoDB para dados, OpenCV e InsightFace para reconhecimento facial, YOLO para deteccao visual e HTML, CSS e JavaScript no cliente web.

Como funciona

Nesta tela, voçe envia o nome e uma foto. O servidor extrai as características do rosto e guarda esse cadastro para que a tela de reconhecimento consiga identificar a pessoa depois.
